# 환경변수

`.env.example` 은 **주석 없이** 유지한다. Hostinger 의 Docker Manager 가 원클릭 배포 때
레포 루트의 `.env.example` 을 환경변수 칸에 **그대로** 복사하는데, 그 칸에는 주석 문법이
없다. `#` 로 시작하는 줄은 `# FOO` 라는 이름의 변수가 되어 "유효하지 않은 변수 이름"
으로 거절된다(2026-09-16 실측). 그래서 설명은 전부 이 문서에 둔다.

`.env.example` 은 `deskrpg init` 이 `.env.local` 의 원본으로 복사하는 파일이기도 하다
(`bin/deskrpg.js`). 쓰지 않는 변수를 넣으면 그 값이 런타임까지 따라가 엉뚱한 실패를
만든다 — 예전에 `DATABASE_URL` 이 남아 SQLite 설치에서 거짓 PostgreSQL 오류가 났다.
**루트 compose 가 실제로 읽는 것만 적는다.**

## 필수

| 변수                        | 설명                                                                                                                                                                                                                                            |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `JWT_SECRET`                | 세션 토큰 서명과 게이트웨이 토큰 암호화에 쓴다. `openssl rand -hex 32` 로 만든다. 자리표시자를 그대로 두면 `deskrpg init` 이 난수로 바꾸지만(`isPlaceholderSecret`), 운영에서는 직접 넣는다. 나중에 바꾸면 접속 중인 사용자가 전부 로그아웃된다 |
| `HERMES_API_KEY`            | 동봉된 Hermes API 서버의 bearer 키. DeskRPG 가 게이트웨이를 등록할 때 쓰는 값이다. **게이트웨이 소유자 키이며 프로필 키가 아니다** — 프로필 키를 넣으면 대화는 되는데 칸반과 크론이 조용히 막힌다                                               |
| `DESKRPG_EDUCATION_WORKFLOW_TOKEN` | DeskRPG와 Hermes 사이 교육·발표 워크플로 API 전용 공유 비밀값. `openssl rand -hex 32`로 별도 생성하며 Slack 메시지나 저장소에 노출하지 않는다. |
| `HERMES_DASHBOARD_PASSWORD` | Hermes 대시보드 비밀번호. 넣으면 `https://deskrpg-hermes.<TRAEFIK_HOST>` 에 대시보드가 열린다(사용자 `admin`, `HERMES_DASHBOARD_USER` 로 변경). 비우면 대시보드는 꺼진다 — 인증 없는 공개 대시보드는 Hermes 가 거부한다                         |

## 모델 제공자 — 하나는 있어야 한다

셋 중 아무거나 하나. 없으면 **Hermes 게이트웨이가 아예 뜨지 않는데, 화면에 보이는 증상은
"직원이 대답을 안 함" 뿐이라** 원인을 찾기 가장 어렵다.

| 변수                 |
| -------------------- |
| `OPENROUTER_API_KEY` |
| `OPENAI_API_KEY`     |
| `ANTHROPIC_API_KEY`  |

다른 공급사를 쓰려면 Hermes 컨테이너 안에서 `hermes model` 로 직접 로그인한다.

## 선택 — 배포

| 변수            | 기본값                                | 설명                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| --------------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DESKRPG_IMAGE` | `ghcr.io/dandacompany/deskrpg:latest` | 비워 두면 최신 릴리스. 도커 매니저 **업데이트** 가 새 릴리스로 올린다. 특정 버전 고정·되돌리기는 `ghcr.io/dandacompany/deskrpg:<릴리스 태그>`. Docker Hub `dandacompany/deskrpg` 는 `2026.9.19` 에서 멈춘 레거시다                                                                                                                                                                                                                                                                                      |
| `TRAEFIK_HOST`  | —                                     | **필수(Hostinger).** 자동 주입되지 않는다(2026-09-17 실측: 없으면 규칙이 `deskrpg.localhost` 가 되어 404). hPanel 경로의 `srvNNNNNN.hstgr.cloud` 를 넣는다                                                                                                                                                                                                                                                                                                                                              |
| `COOKIE_SECURE` | 파일마다 다르다 — 아래                | `true` 면 쿠키에 `Secure` 가 붙어 **HTTP 로는 로그인이 저장되지 않는다**(2026-09-18 실측: Safari 는 localhost 포함 전부, Chrome 은 사설 IP 에서 가입·로그인 API 가 200 인데 `/auth` 에 머문다). 기본값은 경로마다 다르다 — 루트 `docker-compose.yml`(Hostinger, HTTPS) 은 `true`, `docker/docker-compose.external.yml`·`docker/docker-compose.lite.yml` 과 `server.js`(npm·`docker run`) 는 `false`. 값을 주지 않으면 `NODE_ENV === "production"` 일 때 `true` 다(`src/lib/jwt.ts` 의 `isSecureCookie`) |

## 선택 — 로컬 개발(PostgreSQL 스택)

`docker/docker-compose.dev.yml` 로 띄울 때만 쓴다.

| 변수                      | 설명                                                                                                                  |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `DATABASE_URL`            | PostgreSQL 접속 문자열                                                                                                |
| `POSTGRES_PASSWORD`       | compose 가 `deskrpg-db` 컨테이너에 주는 비밀번호. 앱의 `DATABASE_URL` 이 이 값으로 조립되므로 **첫 기동 전에** 정한다 |
| `DB_TYPE` / `SQLITE_PATH` | PostgreSQL 대신 SQLite 로 돌릴 때                                                                                     |

## 선택 — 호스트 Hermes 연동 (기본 꺼짐)

| 변수                              | 설명                                                                                                                                                                                                                                                                                                                                                                                   |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DESKRPG_LOCAL_DISCOVERY_ENABLED` | 이 인스턴스가 **호스트 파일시스템**(`~/.hermes/profiles`)에서 Hermes 프로필을 읽게 한다. 루프백 게이트웨이용이다. **머신 운영자의 시크릿을 읽으므로 게이트웨이 레코드를 소유한 것만으로는 동의가 되지 않는다** — 운영자가 여기서 직접 켜야 하고 게이트웨이 URL 도 루프백이어야 한다. 구성원 전원에게 호스트의 Hermes API 키를 그냥 넘길 수 없는 다중 사용자 인스턴스에서는 켜지 않는다 |
| `DESKRPG_HOST_SETUP_ENABLED`      | 게이트웨이 설정 마법사의 호스트 조작. **`system_admin` 에게 기본으로 열린다**, `0` 이면 끈다. 로컬 Hermes 점검·설치·플러그인 준비·범위 제한 서비스 재시작이 가능하다. 로컬은 `python3`(컨테이너 안에 Hermes 가 없으면 로컬은 닫힌다), SSH 는 `ssh` 가 DeskRPG 서버에 있어야 한다                                                                                                       |
| `DESKRPG_SETUP_SSH_HOSTS`         | 운영자가 명시적으로 승인한 `~/.ssh/config` 별칭(쉼표 구분). 예: `dev-hermes`                                                                                                                                                                                                                                                                                                           |

## 선택 — 자동화 폴러·사건 싱크

양의 정수만 인정하고, 아니면 기본값으로 떨어진다.

| 변수                            | 기본값  | 설명                                              |
| ------------------------------- | ------- | ------------------------------------------------- |
| `AUTOMATION_POLL_ACTIVE_MS`     | `5000`  | 채널에 접속 소켓이 있을 때 폴링 주기(ms)          |
| `AUTOMATION_POLL_IDLE_MS`       | `60000` | 아무도 없을 때 폴링 주기(ms)                      |
| `AUTOMATION_POLL_PAGE_LIMIT`    | `200`   | 한 페이지에 받을 사건 수                          |
| `AUTOMATION_POLL_MAX_PAGES`     | `10`    | `has_more` 를 따라가는 페이지 수 상한(한 바퀴)    |
| `AUTOMATION_RESULT_MAX_CHARS`   | `2000`  | 크론 결과 본문 길이 상한(초과 시 앞부분 + `…`)    |
| `AUTOMATION_EVENT_DEDUPE_LIMIT` | `1000`  | 채널별로 기억하는 최근 사건 ID 수(중복 처리 방지) |
